🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════
Backend won't start?
  → Check .env file exists in /server folder
  → Run: cd server; node test-env.cjs

Database connection fails?
  → Run: cd server; node test-db-connection.cjs
  → Check DATABASE_URL in .env

Frontend can't reach backend?
  → Check CORS_ORIGIN=http://localhost:5173 in .env
  → Restart backend server

Registration fails?
  → Check server logs in backend terminal
  → Run: powershell -ExecutionPolicy Bypass -File test-register-curl.ps1
